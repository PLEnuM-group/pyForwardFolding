    pyForwardFolding.backend¶

    The JAX-based numerical backend. The Backend protocol defines the operations that factors, binnings, and likelihoods rely on; JAXBackend is the concrete implementation. The default instance is exposed as pyForwardFolding.backend.backend.

    If you write custom factors, prefer backend.<op> over importing JAX or NumPy directly — it keeps your code differentiable and JIT-compatible.

    def poiss_rng(self, lam: ArrayLike) -> JAXArray:
    """
    Generate random numbers from a Poisson distribution.

    Args:
        lam (ArrayLike): The rate parameter (lambda) of the Poisson distribution.
        seed (int): Random seed for reproducibility.

    Returns:
        JAXArray: Random numbers drawn from the Poisson distribution.
    """
    key, new_key = jax.random.split(self.rng_key)
    self.rng_key = new_key
    lam = jnp.asarray(lam)
    return jax.random.poisson(key, jnp.asarray(lam))
